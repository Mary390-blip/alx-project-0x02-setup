# Next.js Project Setup and Basics

## 📌 Introduction
This repository contains the setup and foundational structure for a Next.js project.  
The purpose of this repository is to practice and understand the basics of initializing, configuring, and running a Next.js application.  

It will serve as a starting point for building and experimenting with Next.js features such as:
- Project structure
- Routing
- Components
- Styling
- Deployment preparation
